# mtdx62-environment Specification

## Purpose

Датчик попутно сообщает освещённость в помещении и расстояние до обнаруженной цели. Эти
измерения нужны для сценариев «включать свет только в темноте» и для настройки зоны покрытия,
поэтому они доступны как отдельные сущности. Значения приходят из библиотеки `mtdx62`, здесь
описано только их представление в Home Assistant.

## Requirements

### Requirement: Датчик освещённости

Для каждого датчика интеграция SHALL создавать сущность освещённости с классом устройства
`illuminance` и единицей измерения «люкс». Значение берётся из атрибута `illuminance`
подсистемы измерений библиотеки без дополнительного преобразования.

Библиотека отдаёт освещённость с шагом в одну десятую люкса; интеграция MUST NOT округлять значение
до целых.

#### Scenario: Значение освещённости

- **WHEN** библиотека сообщает `illuminance = 4.2`
- **THEN** сущность освещённости показывает 4.2 люкса и состояние `4.2`

#### Scenario: Освещённость меняется

- **WHEN** значение меняется с 4.2 на 0.7
- **THEN** сущность освещённости обновляется до 0.7 люкса без перезапуска

### Requirement: Датчик расстояния до цели

Для каждого датчика интеграция SHALL создавать сущность расстояния с классом устройства
`distance` и единицей измерения «метр».

Библиотека отдаёт расстояние в метрах с точностью до сантиметра; интеграция MUST отдавать его в
метрах без преобразования и MUST NOT округлять до целых.

Отображаемая точность — два знака после запятой, как разрешение датчика.

#### Scenario: Расстояние до человека

- **WHEN** библиотека сообщает `distance = 2.5` метра
- **THEN** сущность расстояния показывает 2.5 метра

#### Scenario: Человека нет

- **WHEN** библиотека сообщает `distance = 0.0`
- **THEN** сущность расстояния показывает 0.0 метра, а не `unavailable`

### Requirement: Расстояние выключено по умолчанию

Сущность расстояния SHALL быть выключена по умолчанию, потому что это вспомогательная величина:
она нужна при настройке зоны покрытия, но не в повседневных автоматизациях.

#### Scenario: Первое добавление устройства

- **WHEN** пользователь добавил новое устройство
- **THEN** сущность расстояния создана, но выключена, а сущности присутствия и освещённости
  включены

### Requirement: Освещённость и расстояние не подменяют недоступность

Если данные не обновляются из-за недоступности датчика, обе сущности MUST переходить в
`unavailable` вместе с сущностью присутствия. Нулевое расстояние при доступном датчике MUST NOT
считаться недоступностью.

Обе сущности следуют правилу достоверности из `mtdx62-presence`: пока код состояния датчика не
равен 1, они MUST быть `unavailable`, а прочитанные значения остаются только в диагностике.

#### Scenario: Датчик недоступен

- **WHEN** интеграция объявила датчик недоступным
- **THEN** сущности освещённости и расстояния находятся в `unavailable`

#### Scenario: Датчик не подтвердил исправность

- **WHEN** датчик сообщает код состояния 2
- **THEN** сущности освещённости и расстояния находятся в `unavailable`, хотя значения в
  регистрах прочитаны
