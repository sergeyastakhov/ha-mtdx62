# Spec Delta

## ADDED Requirements

### Requirement: Код MAC доступен для диагностики

Интеграция SHALL создавать сущность «Код MAC» из регистра `0x000D`: только чтение, категория
«диагностика», выключена по умолчанию.

Имя и описание SHALL говорить, что это один регистр, а не полный MAC-адрес.

Значение SHALL попадать в выгрузку диагностики вместе с остальными параметрами.

#### Scenario: Сущность создаётся выключенной

- **WHEN** пользователь добавляет датчик
- **THEN** сущность кода MAC создана, но выключена, и в обычном списке её не видно

#### Scenario: Значение после включения

- **WHEN** пользователь включает сущность
- **THEN** она показывает код, который отдаёт датчик, без преобразования

#### Scenario: Выгрузка диагностики

- **WHEN** пользователь скачивает диагностику
- **THEN** код MAC виден среди параметров устройства
