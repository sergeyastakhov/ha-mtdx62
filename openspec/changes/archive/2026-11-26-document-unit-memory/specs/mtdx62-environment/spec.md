# Spec Delta

## ADDED Requirements

### Requirement: Единица измерения запоминается Home Assistant

Интеграция SHALL объявлять единицу измерения сущности, а не пересчитывать значение под выбранную
пользователем единицу.

Home Assistant запоминает единицу, с которой сущность была создана, и при изменении объявленной
единицы продолжает показывать прежнюю с пересчётом.

Интеграция MUST NOT переписывать единицу или опции сущности в реестре: там же лежит осознанный
выбор пользователя.

#### Scenario: Релиз изменил единицу

- **WHEN** версия интеграции объявляет для существующей сущности новую единицу
- **THEN** сущность продолжает показывать прежнюю единицу, потому что Home Assistant сохранил её и
  пересчитывает значение

#### Scenario: Сущность создана заново

- **WHEN** пользователь удаляет и добавляет датчик после такого релиза
- **THEN** сущность создаётся с новой единицей

#### Scenario: Пользователь выбрал единицу сам

- **WHEN** пользователь в настройках сущности выбрал другую единицу измерения
- **THEN** интеграция оставляет этот выбор в силе и не возвращает свою единицу
