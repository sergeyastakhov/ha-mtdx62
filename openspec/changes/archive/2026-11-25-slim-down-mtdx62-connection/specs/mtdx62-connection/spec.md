## ADDED Requirements

### Requirement: Заводские параметры связи датчика

Датчик MTD062-MB и MTD262-MB работает на 9600 бод, 8 бит данных, без чётности и с одним
стоп-битом. Значение регистра чётности `0` означает «нет чётности», а не «чётность не задана».

Интеграция MUST предлагать эти значения как значения по умолчанию, а документация MUST
указывать, откуда они взяты: из руководства производителя и сканов.

#### Scenario: Открытие формы для последовательного порта

- **WHEN** пользователь выбирает «Последовательный порт»
- **THEN** в форме уже заданы 9600 бод, чётность «Нет», один стоп-бит и адрес 1

#### Scenario: Отправка формы без правки полей

- **WHEN** пользователь оставляет параметры обмена как есть и указывает только порт и адрес
- **THEN** созданная запись хранит 9600 бод, чётность «Нет» и один стоп-бит, потому что датчик
  отвечает на 9600 8N1, а регистр чётности у него равен `0` («нет чётности»)
