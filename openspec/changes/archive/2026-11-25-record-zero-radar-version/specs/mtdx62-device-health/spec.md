# Spec Delta

## MODIFIED Requirements

### Requirement: Диагностические сущности версий прошивки

Интеграция SHALL создавать диагностические сущности версии приложения и версии радарного модуля,
выключенные по умолчанию. Значения берутся из свойств `app_version` и `radar_version` библиотеки и
показываются в том виде, в каком их сообщает устройство.

Если устройство сообщает нулевую версию, сущность SHALL показывать `0.0.0`. Подменять её на
«неизвестно» MUST NOT: нули — это ответ устройства, а не отсутствие ответа.

#### Scenario: Версии прошивки

- **WHEN** библиотека сообщает `app_version = 1.2.3` и `radar_version = 0.1.2`
- **THEN** сущность версии приложения показывает `1.2.3`, а сущность версии радара — `0.1.2`

#### Scenario: Прошивка не сообщает версию радара

- **WHEN** библиотека сообщает `radar_version = 0.0.0`, потому что регистры версии радара пусты
- **THEN** сущность версии радара показывает `0.0.0`

#### Scenario: Значения версий нет вовсе

- **WHEN** регистры версии не прочитаны и библиотека отдаёт `None`
- **THEN** сущность версии находится в состоянии «неизвестно»
