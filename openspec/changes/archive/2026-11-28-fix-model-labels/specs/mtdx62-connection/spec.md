# Spec Delta

## ADDED Requirements

### Requirement: Модель выбирается по названию

Список моделей в мастере настройки SHALL показывать названия устройств, а не ключи: «MTD062-MB
(5.8 ГГц)» и «MTD262-MB (24 ГГц)» по-русски, «MTD062-MB (5.8 GHz)» и «MTD262-MB (24 GHz)»
по-английски.

Каждый вариант выбора SHALL иметь подпись в `strings.json` и в обоих файлах переводов; набор
подписей SHALL совпадать с набором моделей, которые поддерживает интеграция.

#### Scenario: Добавление устройства

- **WHEN** пользователь открывает шаг выбора модели
- **THEN** он видит два названия моделей с частотой, а не `mtd062-mb` и `mtd262-mb`

#### Scenario: Перенастройка

- **WHEN** пользователь открывает перенастройку записи
- **THEN** выбранная модель подписана так же, как при добавлении

#### Scenario: Подпись забыли

- **WHEN** в интеграции появилась новая модель без подписи в переводах
- **THEN** тест падает, а не выпускается интерфейс с ключом вместо названия
